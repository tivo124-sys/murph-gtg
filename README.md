# Murph GTG

Personal grease-the-groove logger for Murph (Memorial Day 2027).

## Live site
Once GitHub Pages is enabled, the app is available at:

https://tivo124-sys.github.io/murph-gtg/

## How to use
1. Open the URL on your phone.
2. Tap the Share button → Add to Home Screen for an app-like experience.
3. Progress is saved in the browser (localStorage).

## Enable GitHub Pages
1. Go to the repository Settings → Pages.
2. Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)`.
3. Save. The site will be live in about a minute.
